# Glossaire du projet ASTER

Ce glossaire centralise les abréviations et les termes employés dans la documentation du projet. Les définitions décrivent leur sens dans ASTER. Lorsqu'un sigle n'est pas développé dans les sources, cette absence est signalée afin de ne pas inventer sa signification.

## 1. Abréviations

| Abréviation | Développement ou définition                                              | Précision dans ASTER                                                                                                                                                              |
| ----------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| API         | Interface de programmation applicative                                   | Moyen technique envisageable pour communiquer avec les services d'administration Windows. Aucune API d'intégration n'est actuellement confirmée.                                 |
| ASTER       | Administration, Supervision et Traçabilité des Équipements et Ressources | Application web s'appuyant sur les mécanismes d'administration à distance fournis par Windows, sans installer d'agent ASTER sur les machines cibles.                              |
| CND         | Commissariat au numérique de la défense                                  | Organisme d'origine de certains matériels. Il n'exerce aucun rôle dans ASTER et aucune connexion à son système n'est prévue.                                                      |
| CPU         | Processeur central                                                       | Mesure de performance évoquée dans le cadrage, sans décision confirmée sur sa remontée.                                                                                           |
| CRUD        | Création, lecture, modification et suppression                           | Ensemble classique d'opérations de gestion. Dans ASTER, le gestionnaire peut créer, consulter et modifier les matériels, mais pas les supprimer.                                  |
| DCU         | Diagramme de cas d'utilisation                                           | Représentation des acteurs et des fonctionnalités auxquelles ils participent dans un domaine fonctionnel d'ASTER.                                                                 |
| DRHAT       | Direction des ressources humaines de l'Armée de terre                    | Entité distincte du pôle formation.                                                                                                                                               |
| DSE         | Dossier de spécifications des exigences                                  | Livrable évalué dans la partie analyse et gestion de projet.                                                                                                                      |
| IDE         | Environnement de développement intégré                                   | Exemple d'application utilisateur dont le processus peut être consulté ou arrêté par un formateur.                                                                                |
| JSON        | JavaScript Object Notation                                               | Format prévu pour l'import de nouveaux matériels.                                                                                                                                 |
| LDAP        | Lightweight Directory Access Protocol                                    | Solution d'annuaire évoquée pour l'authentification, mais non confirmée.                                                                                                          |
| MCD         | Modèle conceptuel de données                                             | Représentation proposée des entités, de leurs propriétés et de leurs associations, indépendante de l'implémentation technique. Le modèle actuel doit être présenté au client pour validation. |
| NP          | Non protégé                                                              | ASTER cible un réseau interne NP disposant d'un accès à Internet.                                                                                                                 |
| P0          | Priorité critique de cadrage                                             | Marque une question dont la réponse conditionne directement la faisabilité ou l'estimation.                                                                                       |
| PDF         | Portable Document Format                                                 | Format du document d'état des lieux généré à partir d'une remontée.                                                                                                               |
| PID         | Process Identifier                                                       | Identifiant numérique d'une occurrence de processus sur un poste pendant son exécution. Un PID pouvant être réutilisé, l'historique l'associe au poste et à la date de démarrage. |
| PFORM       | Pôle formation                                                           | Entité distincte de la DRHAT.                                                                                                                                                     |
| RG          | Règle de gestion                                                         | Contrainte confirmée portant sur les données, les droits ou les traitements réalisés par ASTER.                                                                                   |
| Scrum-XP    | Association de pratiques Scrum et Extreme Programming                    | Organisation Agile attendue dans les éléments d'évaluation du projet.                                                                                                             |
| SSO         | Authentification unique                                                  | Piste d'intégration évoquée dans le cadrage, sans solution confirmée.                                                                                                             |
| V1          | Première version utilisable                                              | Version couvrant la gestion des matériels et une démonstration simulée de la gestion des processus pour une école.                                                                |

## 2. Termes métier et fonctionnels

| Terme                                       | Définition dans ASTER                                                                                                                                                                                                                                                                                                              |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Administrateur                              | Profil rattaché à une école et disposant de tous les droits dans cette école, notamment pour la gestion des comptes, l'administration, la masterisation des postes et la consultation des statistiques d’utilisation.                                                                                                            |
| Affectation                                 | Rattachement d'un matériel à une salle. Elle prend effet immédiatement et ne possède pas de période de validité.                                                                                                                                                                                         |
| Application métier                          | Terme employé pour une application dite « de base » présente sur un poste. Aucune définition métier plus précise n'est actuellement confirmée.                                                                                                                                                                                     |
| Aptitude                                    | Garantie d'un matériel. Sa gestion est facultative.                                                                                                                                                                                                                                                                                |
| Bâtiment                                    | Information portée par la salle pour indiquer son bâtiment ; le bâtiment ne constitue pas une entité autonome.                                                                                                                                                                                                                                                                      |
| Compte Windows | Entité `COMPTE_WINDOWS` représentant un compte Windows, distinct d'un utilisateur ASTER et d'une connexion particulière. Elle possède l'identifiant interne `Id_compte` et le champ `nom_utilisateur`, correspondant au nom du compte Windows. Un même nom utilisé sur plusieurs postes représente la même entité. |
| École                                       | Établissement de formation nommé, constituant le niveau supérieur de l'organisation géographique gérée par ASTER.                                                                                                                                                                                                                  |
| État des lieux                              | PDF généré à partir du formulaire d'une remontée. Il contient le matériel ou son type, le type de problème, sa description et l'emplacement lorsqu'il est renseigné.                                                                                                                                                               |
| Exécution                                   | Association ternaire reliant un processus, un compte Windows et un poste. Elle porte les dates de démarrage, de détection et d'arrêt.                                                                                                                                                                                      |
| Formateur                                   | Profil rattaché à une école, pouvant accéder aux salles de cette école, consulter et arrêter les processus utilisateur remontés et créer une remontée.                                                                                                                                                                                                                |
| Gestionnaire                                | Profil rattaché à une école et chargé de la gestion de ses stocks et affectations. Il peut créer, consulter et modifier les matériels de cette école, sans les supprimer.                                                                                                                                                                                        |
| Hors garantie                               | Situation d'un matériel dont la date de fin de garantie est atteinte, uniquement si le bonus de gestion de la garantie est réalisé.                                                                                                                                                                                                |
| Hors service                                | État binaire d'un matériel. La valeur par défaut lors de sa création est « non ».                                                                                                                                                                                                                                                  |
| Liste blanche                               | Liste des processus explicitement reconnus comme autorisés. Leur exécution est visible en temps réel, sans historique.                                                                                                                                                                                                             |
| Liste noire                                 | Liste des processus interdits. Une détection provoque l'arrêt automatique du processus, une alerte et la conservation d'un historique.                                                                                                                                                                                             |
| Matériel                                    | Équipement informatique enregistré dans l'inventaire d'ASTER et relevant de la gestion du parc. Il peut être affecté à une salle ou rester en stock sans localisation ; il n'est pas relié au poste de supervision dans le modèle conceptuel.                                                                                                  |
| Masterisation                               | Action de réappliquer une image système sur un poste Windows. L'administrateur ou le super administrateur la demande depuis ASTER ; son exécution s'appuie sur les mécanismes de déploiement Windows qui restent à identifier.                                                                                                                                |
| Mécanismes d'administration Windows         | Services et protocoles fournis par Windows qu'ASTER utilise à distance, sans agent propre, pour consulter les applications et les processus, demander leur arrêt et déclencher les opérations d'administration prises en charge. Le choix précis et la configuration restent à définir.                                          |
| Poste                                       | Entité autonome de supervision accueillie dans une salle. Elle participe avec `PROCESSUS` et `COMPTE_WINDOWS` à l'association ternaire `exécuter`. Elle ne spécialise pas `MATERIEL`.                                                                                                                                         |
| Poste déconnecté                            | Poste n'ayant produit aucune remontée pendant environ quinze secondes. Il reste visible dans sa salle, sans processus affiché.                                                                                                                                                                                                     |
| Processus interne ou système                | Processus du système d'exploitation exclu des données de supervision présentées au formateur et ne pouvant pas être arrêté par celui-ci.                                                                                                                                                                                           |
| Processus non référencé                     | Processus absent de la liste blanche et de la liste noire. Il reste autorisé et visible en temps réel, et sa détection est historisée.                                                                                                                                                                                             |
| Processus utilisateur                       | Programme identifiable représenté par un identifiant et un nom, distinct d'une exécution particulière. L'association `exécuter` décrit son exécution sous un compte Windows sur un poste.                                                                                                                                                                                                           |
| Remontée utilisateur                        | Enregistrement d'un problème concernant un ou plusieurs matériels, déclaré par un formateur, un administrateur ou un super administrateur authentifié au moyen d'un formulaire. Sa localisation éventuelle provient des matériels concernés ; elle n'est pas rattachée directement à une salle. Le statut (« en attente », « remplacé » ou « corrigé ») porte sur la remontée entière, y compris lorsqu’elle concerne plusieurs matériels.    |
| Salle                                       | Entité nommée rattachée à une école et portant l'information de son bâtiment. Elle peut accueillir des matériels et des postes supervisés.                                                                                                                                                                                                                |
| Stock                                       | Situation d'un matériel sans affectation à une salle et sans localisation. Ce terme n'est pas une valeur de l'état « hors service ».                                                                                                                                                                                         |
| Super administrateur                       | Profil non rattaché à une école, disposant des mêmes droits que l’administrateur sur l’ensemble des écoles, notamment pour la gestion globale des comptes ASTER. |
| Supervision                                 | Consultation depuis l'application web ASTER des processus, des utilisateurs et des postes associés dans une salle. ASTER interroge et commande les postes par les mécanismes d'administration Windows ; les échanges sont simulés pour la démonstration.                                                                            |
| Utilisateur ASTER                           | Personne disposant d'un login, d'un mot de passe et d'un profil administrateur, gestionnaire, formateur ou super administrateur. Les trois premiers profils sont rattachés à une école ; le super administrateur ne l’est pas.                                                                                                                       |
| Utilisateur de session | Terme employé pour l’utilisateur associé aux programmes exécutés sur un poste supervisé, représenté dans le modèle par son compte Windows ; voir « Compte Windows ». Il ne constitue pas une entité supplémentaire. |

## 3. Conventions de lecture des diagrammes

Les acteurs généraux ou abstraits des DCU regroupent des participations communes ; ils ne constituent pas des profils supplémentaires dans ASTER.

| Acteur abstrait | Participations communes | Profils concernés |
| --- | --- | --- |
| Acteur de gestion du parc | Actions de gestion du parc accessibles au gestionnaire, sans suppression de matériel | Gestionnaire, administrateur et super administrateur |
| Acteur de supervision | Consultation de la supervision, arrêt manuel des processus utilisateur et réception des alertes de processus blacklistés | Formateur, administrateur et super administrateur |
| Auteur de remontée | Création d'une remontée | Formateur, administrateur et super administrateur |
| Consultant des remontées | Consultation des PDF d'état des lieux et du tableau de bord des remontées | Gestionnaire, administrateur et super administrateur |

Les services Windows d'administration à distance apparaissent comme participants secondaires dans les DCU dont la frontière est l'application web ASTER. Les diagrammes de cas d'utilisation utilisent Mermaid pour représenter les acteurs, cas et relations ; cette représentation ne constitue pas à elle seule une notation UML formellement complète.
