# Présentation client ASTER du 4 novembre 2026

Cette présentation web fonctionne sans dépendance externe et sans installation.

## Lancer la présentation

Ouvrir `index.html` dans Firefox ou un autre navigateur récent.

Pour la servir localement avec Node.js depuis la racine du dépôt :

```powershell
node presentations/2026-11-04-point-etape-client/serve.js
```

Puis ouvrir `http://127.0.0.1:4173/presentations/2026-11-04-point-etape-client/`.

## Commandes

- flèches gauche et droite, espace : changer de diapositive ;
- `F` : passer en plein écran ;
- `N` : afficher ou masquer les notes ;
- `?` : afficher l'aide.
